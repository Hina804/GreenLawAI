# Starter Example

Welcome to the starter example for LlamaIndex. This guide will walk you through building a simple application.

## Prerequisites

Ensure you have Python installed and install LlamaIndex:

```bash
pip install llama-index
```

Set up your API key:

```bash
export OPENAI_API_KEY="your-api-key"
```

## Load Data and Build Index

Create a directory `data` and put your documents inside.

```python
from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

# Load documents from directory
documents = SimpleDirectoryReader("data").load_data()

# Create vector store index
index = VectorStoreIndex.from_documents(documents)

# Query the index
query_engine = index.as_query_engine()
response = query_engine.query("Calculate 1234 times 4567")
print(response)
```

## Running the Code

Run the python script:

```bash
python starter.py
```
